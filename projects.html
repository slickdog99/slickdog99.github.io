Transformer From Scratch

Repository ↗

The full encoder–decoder Transformer of Vaswani et al. implemented from scratch in PyTorch: multi-head and causally masked attention, sinusoidal positional encoding, cross-attention, residual and layer-norm blocks, with per-language WordLevel tokenizers. Trained on the English–Hindi pair of opus-100 and evaluated with CER, WER and BLEU; causal masking verified through attention heatmaps.

Honest result

At 20 epochs the run has not converged to fluent output (BLEU ≈ 0) — the architecture, not the translation quality, is what this repository demonstrates.

Vision Transformer for Breast Cancer Detection

Repository ↗

A Vision Transformer in PyTorch applied to the RSNA breast cancer detection dataset, with patch embedding and a medical-imaging preprocessing pipeline.

Fashion-MNIST CNN Classifier

Repository ↗

A TinyVGG-style convolutional network in PyTorch trained on Fashion-MNIST, built from custom Conv2D blocks with per-epoch metric tracking.

Neural Network from Scratch

Repository ↗

A fully connected network written in NumPy alone — forward propagation, backpropagation, softmax with cross-entropy, and gradient descent, with no deep-learning framework — trained on MNIST handwritten digits.
